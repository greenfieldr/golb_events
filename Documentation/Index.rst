Golb Events - Events The Page Way

----

Golb Events turns regular TYPO3 pages into events. It is an add-on to the
blog extension Golb: an event is a page of the "Event" page type that is
edited like any other page, uses the page tree for structure, backend
layouts and content elements for its content, and carries its dates,
location, organizer and recurrence as page metadata. Frontend plugins
list upcoming and past events and render a month calendar.
